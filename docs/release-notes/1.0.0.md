# Sift 1.0.0

Sift is a Spotlight-style launcher for GNOME Shell 51: search apps, files,
folders, settings, calculations, and the web; open an A-Z app grid; and switch
workspaces with live window thumbnails and liquid glass.

This is the first stable release.

## Install

The one-line installer downloads the release, verifies `SHA256SUMS`, and
installs under `~/.local` without root:

```bash
curl -fsSL https://github.com/AlphaBeast97/sift/releases/latest/download/get.sh | bash
```

Or install a package:

```bash
# Debian / Ubuntu
sudo apt install ./sift_1.0.0_amd64.deb

# Fedora / openSUSE
sudo dnf install ./sift-1.0.0-1.x86_64.rpm

# Arch Linux
sudo pacman -U ./sift-1.0.0-1-x86_64.pkg.tar.zst
```

After a package install, enable the extension for your user and log out and
back in on Wayland:

```bash
gnome-extensions enable sift@alphabeast97.github.io
```

## Highlights

- **Search**: apps, file and folder names, settings panels, arithmetic and unit
  conversions, and optional web results. Local-first; file contents are never
  read.
- **App grid**: A-Z, recent, most-used, or smart order, with keyboard paging
  and app actions.
- **Workspaces**: live thumbnails, minimized windows kept in place, drag and
  drop, workspace reordering, and one-click close.
- **Liquid glass**: Auto, Light, Dark, and Clear modes; Liquid, Crystal, Glow,
  and Flat styles.
- **Login takeover**: with the GNOME overview disabled, login goes straight to
  the desktop and Sift never loads at GDM.
- **Fast first open**: the app grid and workspace view are correct and
  responsive after login, logout, or an extension reload.
- **Updates**: check and install new releases from Preferences → Updates, or
  let Sift check once a day in the background.
- **Diagnostics**: run `sift --doctor` to check the shell, extension, daemon,
  D-Bus service, config, cache, and inotify limit.
- **Clean uninstall**: `make uninstall` removes the extension, binaries,
  service file, settings, learned ranking, config, cache, and index data.
- **Packages**: `.deb`, `.rpm`, and Arch `.pkg.tar.zst` builds for systems that
  prefer a system package over the user installer.

## Requirements

- GNOME Shell 51 on Wayland or X11.
- Linux x86_64 for prebuilt packages. Other architectures build from source.
- glibc 2.35 or newer for the prebuilt daemon (Ubuntu 22.04+, Debian 12+,
  Fedora 36+).

## Notes

- On Wayland, GNOME Shell only rescans extensions at login. Log out and back in
  after installing or updating.
- Web search and settings-panel search are off by default.
- Learned search choices stay local and do not expire. The app-grid **Most
  used** and **Smart** orders use recency-weighted counts; **Recent** uses the
  last launch time.
- `SHA256SUMS` verifies the installer bundle and packages.
