# Sift

Spotlight-style search for GNOME Shell 51: apps, files, calculator and unit
conversion, an app grid, and liquid glass.

Status: in development. M0 (glass and Overview takeover spike) is complete. The
extension skeleton and test harness are being built; there is no installable
release yet.
